# Vajraah Digital — Creative Website

A responsive single-page website for Vajraah Digital. Built with plain HTML, CSS and JavaScript for GitHub Pages.

## Files
- `index.html` — content and structure
- `styles.css` — responsive design
- `script.js` — mobile navigation and year
- `assets/logo.webp` — logo asset
- `CNAME` — custom domain

## Deploy to GitHub Pages
1. Upload the contents of this folder to the repository root.
2. Repository Settings → Pages → Deploy from a branch.
3. Select `main` and `/ (root)`, save.
4. Add `vajraah.com` as the custom domain in Pages.
5. In DNS, use GitHub Pages A records for `@` and CNAME `www` to `mramitparmar17-debug.github.io`.
6. Wait for DNS check/certificate, then enable Enforce HTTPS.
